# MarketNest demo illustrations

These 28 original illustrations were drawn for this project. They depict the item or service named on each image and are marked as illustrative demo placeholders. No marketplace advertisement, product photograph, third-party stock image, or logo was used. Brand names in listing titles identify the fictional examples.

The artwork is supplied for use and redistribution with the MarketNest demo. There is no third-party image license or attribution requirement. Every image is an 800 × 500 WebP file. Secondary illustrations show alternate views, details, or crops for the iPhone, sofa, Swift, and event photography gallery examples.
